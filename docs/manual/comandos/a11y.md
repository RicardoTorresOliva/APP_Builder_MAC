# a11y

## Qué hace y cuándo usarlo

Verifica que cualquier persona pueda usar la interfaz, incluida gente que navega solo con teclado o con lector de pantalla. Úsalo en cada tarea de interfaz, siempre antes de publicar.

## Qué escribes

```text
/a11y pedidos
```

## Qué hará el agente y qué obtienes

- Revisa contraste de colores, navegación solo con teclado, y que el foco se vea claramente.
- Revisa que las imágenes tengan texto alternativo y los elementos una etiqueta clara para lectores de pantalla.
- Corre un chequeo automático si la herramienta lo permite, y lo complementa revisando a mano.

**Obtienes:** el nivel de accesibilidad alcanzado, y cualquier excepción justificada.

## Errores comunes y cómo salir

- Ningún problema de accesibilidad que le impida a un grupo de personas usar el proyecto llega a publicarse.
